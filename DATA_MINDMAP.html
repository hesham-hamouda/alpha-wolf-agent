🎯 ROOT: What is the Body?

Alpha Wolf Body — Persistent memory + knowledge extension
Persists across sessions. Compensates for small (8B) model. Where Alpha Wolf stores everything it learns.

Why this exists: Quхائд's verbatim directive: "الفرق بينه وبين نماذج الذكاء العاديه ان نموذج الذكاء الاساسى حجمه ليس كبير ولكن امتداده قواعد البيانانات والذاكره وخلافه"

Without body: Model forgets everything on session restart. No knowledge accumulation. No self-curation.

With body: Alpha Wolf grows. Every interaction stored. Every lesson learned. Every tool registered. Persistent across weeks.

AGORA-inspired: Multiple specialized KBs (one per domain) connected via knowledge graph (per https://github.com/yifanzhang-pro/agora).

🏗️ LAYER 1: 4-Layer DB Stack (hybrid)

CRITICAL L1. ChromaDB 1.4.0 — Vector DB (12 collections)
~/packages/core/models/chromadb | Already installed | HNSW index | ~30-50ms query

What: Stores embeddings of every text chunk for semantic search.

Why ChromaDB (not LanceDB/Qdrant): Already installed. Battle-tested. Multi-language. Persistent storage built-in. ~200MB RAM.

12 collections (one per domain):

  • kb_self — Alpha Wolf's identity + memories
  • kb_science_marine — oysters, algae, coral
  • kb_science_agriculture — crops, yield, fertilizers
  • kb_science_chemistry — molecules, drugs, reactions
  • kb_science_climate — ClimateBERT, time-series
  • kb_science_proteomics — ESM2, ProtBERT, DNABERT
  • kb_vision — Florence-2, BiomedCLIP, SAM
  • kb_code — CodeAlpaca distilled
  • kb_reasoning — Bespoke-Stratos style
  • kb_mistakes — Mistake log + lessons
  • kb_goals — Active goals + progress
  • kb_tools — Tool registry

Metadata schema (per document):

{
    "evidence_score": float,    // 0-1, AGORA-style
    "citation_count": int,      // how many times cited
    "reuse_count": int,         // how many times retrieved
    "last_used": ISO8601,       // for decay/cleanup
    "source_agent": str,        // "alpha-wolf" | "user" | "hf-fetcher"
    "domain": str,
    "confidence": float
}

Why metadata? Enables AGORA's evidence_score + reuse_count pattern for neglected-branch detection.

CRITICAL L2. NetworkX 3.6.1 — Typed Knowledge Graph
~/packages/core/models/networkx | Already installed | 10 node types | 11 edge types | ~10ms traversal

What: Stores entities (concepts, tools, persons, datasets, mistakes, goals, reflections, episodes, KBs) and typed relations between them.

Why NetworkX (not JSON file): Phase 6 plan said "edges.json" — that's schema-free JSON with no queries. NetworkX = typed edges + O(traversal) queries.

10 Node Types: Concept, Tool, Person, Place, Dataset, Mistake, Goal, Reflection, Episode, KB

11 Edge Types (typed!):

  • trains_on (Goal → Dataset)
  • depends_on (any → any)
  • knows_about (Agent/Concept → any)
  • similar_to (any → any, weighted)
  • learned_from (Mistake → Episode)
  • applies_to (Tool → Goal)
  • blocks (Mistake → Goal)
  • achieves (Episode → Goal)
  • contradicts, supports, replaces (utility)

Why typed? Untyped edges (Phase 6 plan) = no queries. Typed edges = "what tools apply to goal X?" in O(traversal).

CRITICAL L3. SQLite (stdlib) — Structured Memory
~/packages/core/models/sqlite | Built-in | 11 tables | ACID + FK | ~5-20ms queries

What: Stores goals, mistakes, episodes, sessions, reflections, tools, entities (graph mirror), relations (graph mirror), projects, curation_log.

Why SQLite (not PostgreSQL):

  • Local-first (no server)
  • Single-file backup (cp one file)
  • ACID transactions
  • FK constraints enforced
  • stdlib (zero install)
  • Sufficient for single-agent scale (millions of rows)

11 tables (full schema in SCHEMA.md):

  1. projects — active project tracker
  2. episodes — episodic memory (Wolf: Self-Aware)
  3. goals — goal tracking (Wolf: Goal Persistence)
  4. mistakes — mistake log (Wolf: Mistake Hunter)
  5. reflections — deep insights (Wolf: Reinforcement Learning)
  6. tools — tool registry (Wolf: Resourceful)
  7. entities — graph node mirror
  8. relations — graph edge mirror
  9. sessions — session grouping
  10. curation_log — audit trail (Iron Law #36)
  11. sqlite_sequence — auto-managed
RECOMMENDED L4. zvec 0.7.0 — Backup Vector Layer
~/packages/core/models/zvec | Already installed | On-demand init | Offline-capable

What: Cold storage for old memories. Complements ChromaDB.

Why zvec (not just ChromaDB): Redundancy. If ChromaDB corrupts, zvec has the backup. If online, ChromaDB is faster.

Status: zvec 0.7.0 has changed API (`.add()` → `.upsert()`) — fix in progress.

🐺 LAYER 2: Wolf Traits → Body Methods

CRITICAL Wolf Trait #1: Mistake Hunter
body.log_mistake() + body.recall_mistakes()

What: Logs every failure with context + what_went_wrong + lesson + prevention + severity.

Why: Alpha Wolf explicitly hunts mistakes (not hides them). Mistake table is the source of truth for what NOT to repeat.

Iron Law: #33 — lessons → code guardrails (each mistake = potential code improvement)

CRITICAL Wolf Trait #2: Goal Persistence
body.track_goal() + body.update_goal_status() + body.recall_goals()

What: Tracks goals with status (open/active/blocked/done/abandoned), priority (1-10), deadline, progress.

Why: Alpha Wolf never abandons a goal without explicit status update. Can resume context after session restart.

RECOMMENDED Wolf Trait #4: Deep Thinking + #7: Reinforcement Learning
body.reflect() + body.recall_reflections()

What: Records insights with trigger + insight + confidence (0-1) + applied_count.

Why: "Failure is data" — each reflection captures a learning moment. applied_count = how often reused.

RECOMMENDED Wolf Trait #5: Resourceful
body.register_tool() + body.list_tools() + body.mark_tool_invoked()

What: Tool registry with invocation count + last_invoked_at tracking.

Why: Alpha Wolf needs to know what tools it can call (function-calling pattern). Tracks which tools are used most.

RECOMMENDED Wolf Trait #6: Self-Aware
body.get_self_summary() + body.health_check()

What: Returns structured dict with current state (Wolf traits + memory stats + project status).

Why: Alpha Wolf knows what it knows. Can introspect. Can report progress.
